# Decentralized Crowdfunding

A crowdfunding dApp where creators launch campaigns and contributors fund them with ETH in exchange for CFD governance tokens (ERC-20). Token holders vote on fund releases and campaign freezes, while unsuccessful campaigns allow refunds.

The project combines Solidity smart contracts, a MetaMask-connected interface, and IPFS campaign metadata, with security measures including snapshot-based voting, reentrancy protection, emergency pausing, and multisignature withdrawals.
